How does Fletcher compare to the other two? How is Fletcher
generally “better” than something like the simple additive checksum?

If we have same numbers, but in different order additive and XOR 
will give same checksums, but Fletcher gives different same result for 
s1, but different one for s2 byte (20 vs 30)

Make some test files to see if it works as expected.

How does performance change as the size of the input file changes?

8. Now let’s look at the code in peterson.s, which implements Peterson’s
algorithm (mentioned in a sidebar in the text). 
Study the code and see if you can make sense of it.

let flag[2],turn,count
function main:
    cx = 1 - self// cx  = 0 if self = 1, 1 if self = 0
    flag[self] = 1;// try to acquire lock, set flag at index of current thread
    turn  = 1 - self // whose thread is next turn
    //spin if the other thread acquired lock before and 
    //turn is still the other one's
    while(flag[1-self] == 1 && turn == 1-self):
        ;
    
    count++
    
    //release lock and make sure turn if other one's so after this unlock
    it can acquire lock (no more spin because of flag and turn update)
    flag[self] = 0 
    turn = 1 - self
